# Security policy

Report suspected vulnerabilities or send security notifications privately to [opensource.troiano86@pm.me](mailto:opensource.troiano86@pm.me).

Please include:

- The package version, or commit hash for an unreleased checkout.
- Your PHP and Laravel versions.
- A minimal reproduction and the expected and actual behavior.
- The potential security impact and any relevant endpoint policy or request settings.

Remove credentials and private application data from examples. Please avoid posting vulnerability details in public issues while a report is being investigated and a fix is being prepared.

For ordinary bugs and feature requests, use the [GitHub issue tracker](https://github.com/wtroiano86/guarded-http/issues).
